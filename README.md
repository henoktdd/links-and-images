# Links and Images - The Odin Project

An HTML foundational project built for The Odin Project curriculum demonstrating proper usage of web navigation, asset embedding, and HTML markup.

## Features

- **Link Implementations:** Practices both absolute links to external web resources and relative file path navigation.
- **Image Formats:** Highlights practical usage of common web graphic formats including JPG, GIF, PNG and SVG.
- **HTML Entities & Encodings:** Demonstrates proper UTF-8 character sets and reserved HTML entity references (`&lt;`, `&gt;`, `&amp;`).
- **Clean Structure:** Valid HTML5 document hierarchy adhering to standard web accessibility and structural formatting rules.
